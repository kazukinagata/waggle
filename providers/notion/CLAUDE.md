# Waggle Notion Provider

Notion-specific provider plugin for waggle.

## Caveats

- Relations must be added ONE AT A TIME via `notion-update-data-source`. Batching multiple `ADD COLUMN RELATION` statements in a single call causes a 500 error.
- Tool names: refer to a tool by what it does or by its unqualified name (e.g. `notion-query`), never by a full `mcp__<server>__<tool>` name. The server part differs per environment — the Desktop Extension, a remote connector named by the organization, or an opaque id such as a UUID in Cowork. When a full name must be written down (e.g. a Cowork Live Artifact's `mcp_tools`), resolve it at run time from the session's tool list.
- Two families of Notion query tools can coexist: the uncapped `notion-query` (Desktop Extension or a remote connector; Notion API `filter`/`sorts` with `page_size` pagination) and the official connector's `notion-query-data-sources`, which shares one query quota across the workspace on some plans. Use the uncapped one first; use the official one only when no uncapped one is available or every uncapped one declined the user (HTTP 401 or 403, or a message that the user lacks permission or must reconnect). Never fall back to `notion-search` for filtered queries. See notion-provider SKILL.md "Querying Tasks".
- The official connector's `notion-update-page` can set relation properties (an array of page IDs or URLs in `update_properties`; it always replaces, so `append` = fetch + merge + write) and files properties (file upload IDs from `notion-create-file-upload`, or URLs). Verified 2026-11-23. The Desktop Extension's `notion-update-relation` / `notion-set-files-property` and the CLI scripts (`update-relations.sh`, `attach-file.sh`, requiring `NOTION_TOKEN`) remain the first choice where available. See notion-provider SKILL.md "Updating Relation Fields" and "Setting the Attachments Property".
- Appending to a files property through the official connector resets the display names of the existing entries (it returns them only as URLs, so they are written back nameless; the files and links themselves are kept). Use the Desktop Extension's `notion-set-files-property` when available, otherwise confirm with the user before appending to a non-empty files property.
- Reading a hosted file's contents: the Desktop Extension's `notion-read-files-property` (v1.3.0+) never returns the signed URL — a hosted entry comes back with `url: null` by design, because that URL is a bearer credential while it lives. The official connector's `notion-fetch` does show signed URLs (and `notion-get-file-download-urls` for body images); download at once and never paste those URLs outside the conversation. `type:"external"` entries are plain URLs for a general-purpose fetcher. Local uploads and downloads need a shell; without one (e.g. claude.ai) only public URLs can be attached. See notion-provider SKILL.md "Reading the Attachments Property".
- Notion does not support hard delete via the API. Use `notion-update-page` with `archived=true` to soft-delete.
- Rate limits (HTTP 429) are retryable — wait for `Retry-After` header seconds, then retry.
